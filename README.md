# plans

City-by-city research docs for the December 2026 Vietnam trip.

- `index.html` — the claim board: all 9 stops on the route, who's covering what
- `hanoi-ninh-binh.html` — Hà Nội (days 2–3) + Ninh Bình day trip (day 4)
- `styles.css` — shared styles; new plan pages just link it

Route overview: https://des-n-dev-turbo.github.io/vietnam-trip/

## Adding a plan

1. Copy `hanoi-ninh-binh.html`, rename it for your city, swap the content.
2. Add/flip your city's row on the board in `index.html`.
3. Push.

To publish via GitHub Pages: repo Settings → Pages → deploy from `main` branch, root.
